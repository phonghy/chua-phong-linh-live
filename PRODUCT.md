# Product context

Chùa An Nhiên LIVE is a local-first Vietnamese interactive livestream temple. The operator uses a desktop admin panel and captures the portrait game in OBS. Viewers participate through free comment commands and optional gifts; the game builds shared temple milestones. The local demo works independently of TikTok and visibly identifies simulated data.

Success: coherent golden temple artwork, understandable animated prayer actions, synchronized controls/overlay, durable SQLite state, moderated public prayers, 40 visible visitors at >=30 FPS on measured development hardware. Node 24, React, Phaser 4.2.1, TypeScript; public/admin contracts live in packages/shared. Current broadcaster has phone-only LIVE access; actual desktop broadcasting is a separate requirement.

The user authorized per-LIVE gratitude boards, gift-only flowers, a local Vietnamese narrator, audience milestones and sharing prompts after v1. Free comment actions remain meaningful; gift-board scores are configured contribution points, not money. No paid competition, themed rooms, daily minigames, cloud deployment, or official TikTok integration. All labels Vietnamese. Core temple audience expects a calm, respectful experience. See AGENTS.md and docs/IMPLEMENTATION_PLAN.md for defaults.
