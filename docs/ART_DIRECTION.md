# Temple asset production

## Approved target
User concept is master reference. First generated hall inspected: symmetrical carved teak, antique gold, amber lanterns, red carpet, a dark niche that accepts an independent altar. Use this as the visual family seed. Native frame 1080×1920; hall stretches proportionally to fill. Main altar bottom-center at (540,1040). Prayer congregation below y=1150.

## Layers and constraints
- Hall: opaque portrait, full frame, no people or UI.
- Altar: transparent, frontal golden seated Buddha on lotus base, flowers/incense/lamps grouped as one independently movable shrine layer; bottom-center pivot.
- Visitors: transparent atlas, two coherent identities, four poses each (standing, kneeling, bowing, offering), back facing altar, consistent baseline per cell; bottom-center pivot.
- Effects: code-authored geometry for sparks, light, incense smoke and lotus-petal motion; no rasterized labels.
- Warm upper-left/bilateral lantern lighting, smooth sampling, restrained bloom. No geometric substitutes for raster character silhouettes.

## Provenance
AI raster assets generated with built-in image_gen; user screenshot used as reference, not shipped as game artwork. Preserve generated originals under their returned tool paths; copy game assets into public/assets. Prompts and normalization are recorded in assets manifest and this document. Inspect native-scale composition and alpha before release.
